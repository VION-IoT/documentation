# Contributing

This project is **source-available**. External contributions (issues, pull requests, discussions) are not accepted.

The source is published under Apache 2.0 so that users of the VION documentation site can read and audit its source — not as an invitation to collaborate.

For questions or problem reports, see [SUPPORT.md](SUPPORT.md).

For security vulnerabilities, see [SECURITY.md](SECURITY.md).
