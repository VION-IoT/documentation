## ServiceAttribute Class

Declare a service  
On a logic block, the Service attribute can be omitted (then class name + all implemented service interfaces are  
used)  
Identifier can be empty (then class name is used)  
ImplementedServiceInterfaces can be empty (then all service interfaces implemented by the class are used)

```csharp
public class ServiceAttribute : System.Attribute
```
