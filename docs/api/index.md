# API Reference

## Dale SDK
The Dale SDK documentation covers the public API surface of the Dale .NET SDK.

- [Dale SDK (Core)](/api/dale/sdk/index.md) — Core runtime types and helpers used by applications.
- [Dale SDK (TestKit)](/api/dale/testkit/index.md) — Testing utilities and mocks provided for unit and integration tests.

## Cloud API
The Cloud API docs describe the HTTP endpoints exposed by the cloud service, including request/response schemas.

- [Cloud API (OpenAPI)](/api/cloud/swagger.json) — The OpenAPI (Swagger) JSON for the Cloud API. Use this with swagger-ui or codegen tools.
