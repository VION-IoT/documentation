# AI-Assisted Development

## Why Dale Works Well with AI Agents

How the SDK's attribute-based, strongly-typed design gives AI agents clear patterns to follow.

## Typed Attributes Enable Reliable Code Generation

How `[LogicBlock]`, `[ServiceProperty]`, `[Interface]`, and other attributes provide structure that AI agents can generate correctly.

## CLI as the Agent's Interface

How `dale build`, `dale test`, and `--output json` give AI agents a reliable feedback loop.

## Product-Neutral Approach

This workflow is not tied to any specific AI product -- it works with any AI coding tool that can run shell commands and edit files.
